# 教育管理系统 - 后端启动说明

## 🚀 快速启动（推荐）

**双击 `start.bat`** 即可一键完成所有步骤（首次运行较慢，需要安装依赖）。

启动成功后会在终端显示 `Local: http://localhost:3000`，**请保持窗口打开**。

## 📝 手动步骤

```bash
# 1. 进入 web 目录
cd web

# 2. 安装依赖（首次）
npm install

# 3. 建表 + 灌入初始数据
npm run db:reset

# 4. 启动开发服务器
npm run dev
```

## ⚠️ 微信开发者工具设置（关键）

后端跑在 `http://localhost:3000`（HTTP），微信默认会拦截，请：

1. 打开微信开发者工具
2. 右上角点 **详情**
3. 选择 **本地设置**
4. ✅ 勾选 **"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"**
5. 点击 **编译** 重新加载

## 🐛 常见问题

**Q: 启动脚本报 "未检测到 Node.js"？**
A: 去 https://nodejs.org 下载 LTS 版本，安装后**重开终端**再运行。

**Q: 数据库数据全是旧的怎么办？**
A: 运行 `npm run db:reset` 强制重建数据库。

**Q: 小程序提示 "网络请求失败"？**
A: 检查三点：
   1. 后端窗口是否显示 `Local: http://localhost:3000`
   2. 微信开发者工具是否勾选了"不校验合法域名"
   3. 设置页的 API 地址是否为 `http://localhost:3000`
